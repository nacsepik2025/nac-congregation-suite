# NAC Congregation Suite

A New Apostolic Church congregation reporting and management app, published as a GitHub Pages site.

## Install the app

The site is a Progressive Web App (PWA) and can be installed from a supported browser while online:

- **Android:** Open the site in Chrome, then choose **Install app** (or **Add to Home screen**) from the browser menu. If the install button appears, you can use that instead.
- **Windows, macOS, or Linux:** Open the site in Chrome or Microsoft Edge and select the install icon in the address bar, or use the browser menu's **Install app** option.
- **iPhone/iPad:** Open the site in Safari, tap **Share**, then **Add to Home Screen**.

The app shell and main page are cached for repeat visits and basic offline access. Data synchronization is not provided by the installable shell; the app's existing storage behavior remains unchanged.
